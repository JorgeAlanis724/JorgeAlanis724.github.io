# JorgeAlanis724.github.io

Raíz del sitio de GitHub Pages de Insight Games: https://jorgealanis724.github.io/

- `index.html` — página de Insight Games (sin dependencias externas; estilos en línea).
  Al publicar un juego, cambiar su etiqueta "Próximamente" por el enlace a su ficha de Play.

- `app-ads.txt` — autoriza a Google AdMob (cuenta de editor `pub-2388619127158212`) a vender
  los anuncios de nuestras apps. AdMob lo busca en `https://jorgealanis724.github.io/app-ads.txt`.
  Sirve para **todas** las apps de esta cuenta de AdMob (Bee-Nito y las que vengan): no hay que
  duplicarlo por app.
- La política de privacidad de Bee-Nito vive en otro repo: `beenito-privacy`
  (https://jorgealanis724.github.io/beenito-privacy/).
